Web Content Accessibility Guideline

Perceivable - User can access information, alt text, captions, suff contrast,zoom and reflow
Operable - use can navigate and control the interface, keyboard access, visible focus, no keyboard traps, enough time
Understandable - Users can understand content and interactions. Clear labels, predictable behavior, helpful error messages.
Robust - Content works with browsers and assistive technologies. Semantic HTML, accessible names and roles, announced status updates.
