Uniform Distribution

# Discrete
A uniform random variable 𝑋 is a random variable wherein a finite number of values are equally likely to be observed.
	
$$
CDF: f_X(x)=\begin{cases}
0 & x \leq a \\
\frac{x-a}{b-a} & a < x \leq b \\
1 & b<x
\end{cases}
$$

$$supp(𝑋)={𝑎,𝑎+1,𝑎+2,…,𝑏−1,𝑏}$$

$$ℙ(𝑋=𝑥)=\frac{1}{b-a+1} for all 𝑥∈supp(𝑋)$$

$$𝔼(𝑋)=\frac{a+b}{2}$$
$$Var(𝑋)=\frac{(𝑏−𝑎+1)^2−1}{12}$$
# Continuous
For a continuous random variable 𝑋, its probability density function (PDF), denoted by 𝑓𝑋(𝑥), is a function that describes the likelihood of 𝑋 taking on a specific set of values.

$$supp(𝑋)=[a,b]={X:0\leq x \leq  b}$$
$$
PDF: f_X(x)=\begin{cases}
\frac{1}{b-a} & \text{if a}\leq x \leq b \\
0 & \text{otherwise}
\end{cases}
$$
