### Supervised Learning
- Teacher gives you labels
- Prediction Problems
- Classification
	- Nearest Neighbor Classification
	- Generative Models Classification
- Regression
	- Linear Regression
	- Logistic Regression
- support vector machines, kernel methods, decision trees, boosting, random forests, neural networks

### Unsupervised Learning
- Teacher gives you no labels
- clustering, projection, manifold learning, embedding, generative modeling

### Reinforcement Learning
- Teacher gives you some labels
- Active Learning: algorithm chooses which examples to label
- Reinforcement Learning: learning how to interact with the world (alpha-go)
