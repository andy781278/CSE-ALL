##### Find
Time (average): $O(1)$
Time (worst case): $O(n)$
##### Insert
Time (average): $O(1)$
Time (worst case): $O(n)$
##### Remove
Time (average): $O(1)$
Time (worst case): $O(n)$

##### Collision Resolution Strategies
- Linear Probing
	- just put it in the next available slot
- Separate Chaining
	- treat each slot as a linked list, and add more to the list if collides
