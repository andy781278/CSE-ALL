Abstract Data Types are theoretical data structures with no implementation, they specify the functions the data types have and what they should store.
Examples:
- Stack, Queue, Deque, List, PQ
- Map, Tree, Graph, Set
- BST, Trie

Data Structures are implementations of the ADTs, they specify specifically how data is stored and how the structure is coded, usually with pseudocode. Each ADT can have multiple different DTs to represent them, each with their own ups and downs in regard to run time.
Examples:
- Array, string, struct, tuple, LinkedList, BST
- BST, AVL, red-black tree
