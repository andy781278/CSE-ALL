10. Use the Pumping Lemma for regular languages to prove that $L = \{ww^R | w \in \{0, 1\}^*\}$ is not regular (where $w^R$ is the reverse of$ w$).

Assume that $L$ is regular.

$\forall$ Reg Lang $L$, $\exists p$ such that $\forall w_t \in L$,  $(|w_t| \geq p) \rightarrow \exists x,y,z$ such that the following is true:
0. $w_t=xyz$
1. $y \neq \epsilon$
2. $|xy| \leq p$
3. $\forall i \geq 0, xy^iz \in L$

Let $p=|w|$, then $|ww^R|=2p$

0. $x=a^{j},y=a^{k},z=a^{p-j-k}a^R, w_t=a^{j}a^{k}a^{p-j-k}a^R$ where $j+k\leq p$
1. $y \neq \epsilon \rightarrow |y|\neq 0$
2. $|xy| \leq p \rightarrow xy=a^{j}a^{k},|a^{j}a^{k}| \leq p$
3. $i=0,xz=a^{j}a^{p-j-k}a^R=a^{p-k}a^R\notin L$ since $a^{p-k}$ is no longer the reverse of $a^R$

There is a contradiction, therefore L is not regular.

11. We studied that regular languages are closed under the following operations: set union, set complement, concatenation, star, reverse. Use these basic operations to prove that regular languages are closed under the following operation

$T (L) = \{w | \text{either both w and wR are in L , or neither of them is in L}\}.$

We can form $T(L)$ by doing $(L \cap L^R) \cup (\overline{L} \cap \overline{L^R})$.
- Union is proven closed
- Reverse is proven closed
- Complement is proven closed
- Intersection can formed on an example $L$ and $M$ doing $\overline{\overline L\cup \overline M}$

Since all of those operations are closed, we can safely say $T(L)$ is also closed.

12. Prove that regular languages are closed under the following operation:

$T (L) = \{w | \text{all proper prefixes of w belong to L}\}$

(Remember that all you need to prove regularity is to have a DFA for it)
All regular languages L have a corresponding DFA M. If $T(L)$ is closed, then we can match  $M'$ to $T(L)$. $M=(Q,\Sigma,\delta,s,F)$
$M'=(Q',\Sigma',\delta',s',F')$
$Q'=Q\cup q_d$
$\forall a \in \Sigma, \forall q_a \in Q', \ \delta'(q_a,a)\rightarrow q_d \ iff \ q_a\notin F$
$s'=s$
$F'=Q$

M' makes every state accepting except for the new qd state. But every state also has a connection to qd if it wasn't in accepting back in M. So every state would go to dead if there was an input and it wasn't already accepting beforehand. But no input means it's accepting by default. Any input, even character by character, has to be accepting in M to be accepting in M'.

Since M' is a valid DFA and L(M') = T(L), T(L) is regular. Therefore regular languages are closed under T.
