Given an input space X, and an output space Y, we need to create a function that maps each X to Y as follows:
$$f: X \rightarrow Y$$
There are three types of prediction problems, categorized by type of output space:
### Discrete

##### Binary Classification
Output is binary
- true or false, yes or no, spam or not spam

##### Multiclass
Output is categorical

##### Structured Outputs
Output is Abstract Data Types
- Trees like parse trees

### Continuous
Output is a range
- $y=[0,\infty)$

### Probability Values
output is a probability
- $y=[0,1]$
